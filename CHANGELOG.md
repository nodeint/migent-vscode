## 0.1.0

- Add read-only monitoring of Migent sessions, workflows, project configuration, timelines, logs, and results.
- Run, prepare, continue and stop Migent sessions from VS Code, including a Run action on each workflow.
- Answer questions that Migent sessions ask from VS Code, with notifications and a question panel that keeps drafts.
- Start or prepare a new workflow session from a completed session's outputs using suggested next steps on Results and a Next step page.
- Reply to blocked sessions with drafts that survive a reload, get notified when a session blocks, fails, waits for provider quota or completes, and run the next stage once, continue without a reply, repair a session, run Doctor and initialize a project.
